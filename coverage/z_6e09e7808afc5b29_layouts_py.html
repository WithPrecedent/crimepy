1"""Where each field is in the records of the NIBRS master files. 

2 

3A NIBRS master file has one record (line) for each segment of each report. 

4The first two characters of a record name its segment (its "level"), and the 

5rest are fixed-width fields. The positions are those of the FBI's "NIBRS 

6Flatfile Yearly Master Record Descriptions" (12/18/95), which is still the 

7documentation that the Crime Data Explorer gives with the files, and of the 

8fields that the FBI added later and that are in the files but not in that 

9document: 

10 

11* Administrative segment (01), position 89: cargo theft (Y or N), in 2013 

12 and later. 

13* Offense segment (02), positions 60-67: bias motivations #2 to #5, in 2013 

14 to 2016. 

15* Victim segment (04), positions 124-135: the officer's activity and 

16 assignment, and the ORI of another jurisdiction (handwritten in the 

17 document), in every year. 

18* Offender segment (05), position 40: the ethnicity of the offender, in 2013 

19 and later. 

20* Batch header (BH), positions 285-292: a date that is the same for every 

21 agency in a state, in 2013 to 2016. 

22 

23Files before 2013 split each agency's batch header into three records ("B1", 

24"B2", and "B3"), and files from 2013 on have one ("BH"). Their fields have the 

25same names here, so `crimepy` makes one table of agencies from either. 

26 

27Positions in `Field` are those of Python slices (counted from 0, with the end 

28excluded), so the document's positions "34-36" are `start = 33, end = 36`. 

29Records shorter than a layout (most records after 2012 drop trailing blanks) 

30are padded with blanks, so fields past their end are missing. 

31 

32Contents: 

33 Field: a field of a record: its name, position, and kind. 

34 Layout: the fields of one kind of record. 

35 KINDS: the kinds of fields. 

36 LAYOUTS: the layout of each segment level, by its two-character code. 

37 TABLES: the name of the table made from each segment level. 

38 SEGMENTS: the segment levels of each table. 

39 

40"""

47# The kinds of fields, and what each becomes: 

48# 'code': a code (such as an offense code), as text, which 

49# `crimepy.nibrs.munge.decode` can replace with its label. 

50# 'text': text, without leading and trailing blanks. 

51# 'int': a whole number. 

52# 'date': a date written as YYYYMMDD. 

53# 'bool': true for "Y", false for "N", and missing otherwise. 

54# 'yes': true if the field is `Field.true`, and false otherwise. 

55# 'quantity': a 12-digit amount of a drug: 9 digits and 3 more digits of 

56# thousandths. 

57KINDS: frozenset[str] = frozenset({ 

58 'bool', 'code', 'date', 'int', 'quantity', 'text', 'yes'})

65class Field: 

66 """A field of a record in a NIBRS master file. 

67 

68 Args: 

69 name: name of the column made from the field. 

70 start: position of the first character of the field, counted from 0. 

71 end: position after the last character of the field. 

72 kind: what the field becomes (see `KINDS`). Defaults to 'code'. 

73 codes: name of the codebook in `crimepy.nibrs.codes.CODEBOOKS` that 

74 gives the labels of a 'code' field. Defaults to `None`, in which 

75 case the field has no labels. 

76 true: the character that means true in a 'yes' field. Defaults to 

77 'Y'. 

78 

79 """ 

80 

81 name: str 

82 start: int 

83 end: int 

84 kind: str = 'code' 

85 codes: str | None = None 

86 true: str = 'Y'

90 def __post_init__(self) -> None: 

91 """Checks the field. 

92 

93 Raises: 

94 ValueError: if the kind is not one of `KINDS` or the field has no 

95 width. 

96 

97 """ 

98 if self.kind not in KINDS: 

99 message = ( 

100 f'{self.kind!r} is not a kind of field: use one of ' 

101 f'{sorted(KINDS)}') 

102 raise ValueError(message) 

103 if self.end <= self.start: 

104 message = f'the field {self.name!r} has no width' 

105 raise ValueError(message)

197def _repeated( 

198 name: str, 

199 first: int, 

200 width: int, 

201 times: int, 

202 kind: str = 'code',

207 name: name of the columns, which are numbered ("offense_1").

209 from 1.

211 times: number of fields. 

212 kind: what the fields become. Defaults to 'code'.

214 

215 Returns: 

216 The fields. 

217 

218 """ 

219 return [ 

220 _field( 

221 f'{name}_{n + 1}', first + n * width, first + (n + 1) * width - 1, 

222 kind, codes) 

223 for n in range(times)]
